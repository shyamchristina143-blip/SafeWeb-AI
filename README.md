# SafeWeb AI

Free, cross-platform adult-content
blocking and internet protection project.

## Project Goals

- Block known adult websites.
- Maintain updated domain databases.
- Protect Android and iPad.
- Support multiple browsers.
- Provide administrator protection.
- Develop AI-assisted content detection.

## Version 0.1

## Privacy
